## [Unreleased]

### Added

- К релизу прикладывается «чистый» исполняемый файл, без установщика — под
  Windows и Linux. Он **не** самодостаточен: линкуется с системными GTK и
  WebKitGTK и на машине без них не запустится, а обновляться сам не умеет —
  подписываются только бандлы. Кому нужен «один файл, скачал и работает», тому
  по-прежнему нужен AppImage.
- Сборка под Alpine Linux: отдельный файл `mkdsc-<версия>-linux-x86_64-musl`.
  Обычные линуксовые артефакты на Alpine не запускаются вовсе — там другая
  библиотека C. adb и scrcpy на Alpine нужно поставить из репозиториев системы
  (`apk add android-tools scrcpy`): приложение скачивает сборки, собранные под
  glibc, и запустить их там нельзя. Установленные в системе оно находит само.

## [2.0.0] — 2026-08-26

### Security

- Приложение больше не открывает локальный сетевой порт: интерфейс общается с
  логикой напрямую, внутри процесса. Вместе с портом исчез и весь класс
  проблем, ради которых понадобились токен, проверки Origin и Host.
- Веб-панель и API закрыты аутентификацией по токену: токен генерируется при
  старте, внедряется в отдаваемую страницу, в десктопной сборке передаётся из
  Rust-лаунчера по IPC.
- CORS больше не открыт всему миру: разрешены только известные origin
  приложения. Раньше любой сайт, открытый в браузере, мог читать и удалять
  файлы подключённого телефона.
- Добавлена проверка заголовка `Host` — защита от DNS-rebinding.
- Бэкенд по умолчанию слушает `127.0.0.1` вместо `0.0.0.0`.
- Включён CSP в десктопной сборке; из него убраны разрешения на обращения к
  локальному серверу — вместе с самим сервером.
- Распаковка скачиваемых архивов защищена от выхода за пределы каталога
  (Zip Slip / Tar Slip), включая проверку целей символических ссылок.
- Загрузка файлов на устройство очищает имя файла — убран обход каталогов
  через `../` в имени.
- Диагностические ADB-команды фильтруются по имени бинаря, а не по подстроке:
  прежний фильтр пропускал `rm -r`, `dd`, `pm uninstall` и при этом блокировал
  безобидные команды.
- Скачиваемые архивы adb и scrcpy проверяются по SHA-256 до распаковки:
  битый или подменённый архив удаляется, установка прерывается с понятной
  ошибкой. Раньше содержимое загрузки не проверялось никак.

### Fixed

- Кнопки «GitHub» и «Telegram» в подвале открывают браузер. Раньше нажатие не
  делало ничего: в окне приложения обычная ссылка с `target="_blank"` не
  работает, открывать новые окна движку не разрешено. По той же причине молча
  не срабатывала и кнопка «Открыть страницу релиза» в проверке обновлений.
  Открываются только адреса github.com и t.me: подменённый ответ GitHub API не
  сможет увести пользователя на произвольный сайт.
- Свёрнутая секция больше не занимает высоту соседней развёрнутой: от неё
  остаётся только заголовок, а освободившееся место забирают остальные.
- Стрелка выпадающего списка перестала размножаться по всей ширине поля при
  нажатии на него. Сокращённое свойство `background` в состоянии фокуса
  сбрасывало картинке-стрелке режим повтора; в светлой теме тот же сброс
  заставлял её просто исчезать.
- Вторая строка карточки устройства (статус, `ip:порт`) больше не наезжает на
  кнопки: она обрезается многоточием, а на узкой карточке кнопки переносятся
  под текст, вместо того чтобы сжимать имя до одной буквы.
- Длинный серийный номер устройства больше не заезжает под кнопки «Сохранить»
  и «Отключить» — строка сжимается и обрезается многоточием.
- Секция файлового менеджера больше не растягивает страницу по горизонтали:
  при обычной ширине окна внизу появлялась полоса прокрутки, а правый край
  карточек уходил за экран.
- Запрос подтверждения («Удалить файл?» и подобные) снова появляется: окну не
  было выдано право показывать такие диалоги, и приложение молча откатывалось
  на диалог движка — на Linux тот всегда отвечал «нет», то есть удаление и
  другие подтверждаемые действия просто не выполнялись.
- Файловый менеджер открывает `/sdcard` и показывает его содержимое. Раньше на
  этом (стартовом) пути был виден один нерабочий элемент: `/sdcard` на Android —
  символическая ссылка, и список показывал саму ссылку вместо папки.
- На Linux приложение снова работает на чистой машине: распакованный adb
  получает бит исполнения. Раньше он извлекался как обычный файл, запустить
  его было нельзя, и приложение бесконечно перекачивало platform-tools.
- Десктопная сборка из чистого клона больше не зависает на экране загрузки.
- Приложение больше не зависает при работе с устройством: блокирующие вызовы
  ADB уведены из главного цикла событий.
- Окно открывается сразу, не дожидаясь скачивания adb и scrcpy; на экране
  загрузки виден прогресс первичной подготовки инструментов.
- Запуск приложения больше не убивает чужой ADB-сервер — отваливались
  Android Studio и другие инструменты.
- Файлы и папки с пробелами в имени обрабатываются корректно. Раньше удаление
  `/sdcard/My Folder` удаляло `/sdcard/My` и `/sdcard/Folder`.
- Символические ссылки в файловом менеджере отображаются корректно
  (на Android `/sdcard` — это ссылка).
- Настройки устройства («не гасить экран», «показывать касания») применяются к
  выбранному устройству; при нескольких подключённых они молча не работали.
- Конфигурация не может быть повреждена через встроенный редактор: добавлена
  валидация. Раньше сохранение `null` в любой секции делало приложение
  неработоспособным без ручной правки файла.
- Запись конфигурации стала атомарной — при сбое больше не теряются сохранённые
  устройства и пресеты.
- Скачивание файла с устройства больше не оставляет копию во временной папке.
- Скриншоты, сделанные в одну секунду, больше не затирают друг друга.
- Логи ротируются и не растут бесконечно.
- В десктопной сборке заработали пути, зависящие от определения окружения Tauri
  (проверка исправлена на `__TAURI_INTERNALS__`).
- Список устройств в десктопном приложении обновляется сразу после
  подключения, отключения и включения режима по Wi-Fi, а не через три секунды.
- Настройки телефона («не гасить экран» и «показывать касания») возвращаются
  как были, даже если закрыть приложение, пока scrcpy ещё работает. Раньше в
  этом случае экран телефона так и оставался включённым при зарядке, и вернуть
  всё обратно можно было только руками в настройках Android.
- Автовыбор подключения в десктопном приложении срабатывает и тогда, когда одна
  из сторон пары «USB + Wi-Fi» не отвечает. Раньше в этом случае рекомендация не
  приходила вовсе и scrcpy запускался по прежнему подключению — то есть ровно в
  той ситуации, ради которой автовыбор и нужен.

### Changed

- Скриншот снимается одним вызовом adb вместо трёх: кадр приходит прямо в
  стандартный вывод (`exec-out`), без записи файла на телефон, его скачивания и
  последующего удаления. Прошивки, которые так не умеют, обслуживаются прежним
  путём. Снимок делается заметно быстрее.
- Новая иконка приложения вместо круга в квадрате.
- Интерфейс переведён на Material 3 и Material 3 Expressive: другая палитра,
  крупные скруглённые карточки, пружинная анимация нажатий, единые кнопки,
  поля и переключатели. Тёмная и светлая темы согласованы между собой.
- Боковое меню стало навигационной панелью Material 3: в свёрнутом виде это
  рельс с иконками и подписями, а не полоска в 60 пикселей с обрезанными
  кнопками. Тема переключается тремя кнопками («Система / Светлая / Тёмная»)
  вместо выпадающего списка.
- Панель файлового менеджера разложена в две строки: сверху адрес и переходы,
  снизу быстрые папки и действия. Раньше десять элементов стояли в один ряд и
  хвост уезжал за край окна.
- Приложение больше не тратит ресурсы на постоянную анимацию фона: размытые
  «шары» и бесконечно едущий градиент убраны, фон рисуется один раз. Это
  заметно на ноутбуке — окно перестало греть процессор, когда с ним ничего не
  делают.
- Интерфейс перестал перерисовываться целиком каждые две секунды: опрос
  устройств и статуса записи обновляет экран только когда данные правда
  изменились, а секундомер записи задевает лишь свою полоску. В простое статус
  записи опрашивается раз в десять секунд вместо двух.
- Шрифты интерфейса берутся системные и подобраны под них размеры и начертания.
  Раньше страница подключала Google Fonts, но политика безопасности приложения
  запрещает обращения наружу — запрос всё равно не проходил, и интерфейс молча
  рисовался запасным шрифтом.
- Длинный список файлов и галерея скриншотов больше не тормозят прокрутку:
  невидимые строки не верстаются, а миниатюры грузятся по мере появления на
  экране.
- Тема применяется до первой отрисовки: при запуске в тёмной теме больше нет
  вспышки белого экрана.
- Загрузка файлов на устройство в десктопном приложении больше не делает
  временную копию: файл уходит на телефон прямо с диска. Раньше каждый файл
  сначала целиком копировался во временную папку, и на гигабайтном видео это
  занимало и время, и место.
- Конфигурацию в десктопном приложении больше не могут перезаписать два
  процесса сразу: файлом распоряжается само приложение. Раньше сохранение
  пресета и сохранение устройства, сделанные одновременно, могли затереть друг
  друга.
- scrcpy скачивается закреплённой версии (4.1), а не «последней доступной»:
  новая установка больше не получает версию, на которой приложение не
  проверялось. Свою версию можно задать через `MKDSC_SCRCPY_VERSION`.
- adb (platform-tools) тоже скачивается закреплённой ревизии r37.0.1 вместо
  «последней доступной» — у `latest` нет публикуемой контрольной суммы.

### Added

- Предупреждение, если найденный scrcpy вне проверенного диапазона версий:
  запуск не блокируется, но видно, почему часть опций может не работать.
- Тесты и CI-workflow.
- ESLint и проверка типов `tsc --noEmit` в сборке фронтенда.
- `config.example.json`.
- `.gitattributes` — нормализация переводов строк.

### Removed

- Python-бэкенд удалён: приложение состоит из Rust и интерфейса, устанавливать
  Python и его зависимости больше не нужно. Установщик стал меньше, а запуск —
  быстрее: раньше окно ждало, пока поднимется второй процесс.
- Веб-панель (`python web_panel.py`) убрана вместе с бэкендом, который её
  отдавал. Всё, что она умела, есть в приложении.
- Кнопка «Скачать logs.zip» убрана: файл отдавал HTTP-сервер, которого больше
  нет. Экспорт логов в выбранную папку остался и делает то же самое.
- macOS больше не поддерживается: сборки под неё не выпускаются. Поддерживаемые
  платформы — Linux x64 и Windows x64.
- Из конфигурации убраны секции `web` (хост, порт, автооткрытие браузера) и
  `cli` (баннер): настраивать в них было уже нечего — и сервер, и CLI удалены.
  Существующий `config.json` чистится сам при первом запуске, остальные
  настройки остаются на месте.
- Каталог `shit/` с логами сессий убран из репозитория.
